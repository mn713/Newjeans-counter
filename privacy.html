Privacy Policy

Last updated: 2026

This app is a personal, non-commercial project used to automatically post a daily countdown video to a single TikTok account that the developer owns.

What data this app accesses

This app uses TikTok's Login Kit and Content Posting API solely to:

  • Authenticate the developer's own TikTok account
  • Upload and publish video content to that same account

What data this app does NOT do

  • It does not collect, store, or share any data about other TikTok users
  • It does not access follower lists, messages, or any personal data beyond what is required to authenticate and post
  • It is not used by, or made available to, any third party

Data storage

Access tokens are stored privately and securely and are used only to authorize posting to the developer's own account. No user data is sold, shared, or used for advertising.

Contact

Questions about this app can be directed to the developer via the contact information associated with this GitHub repository.
